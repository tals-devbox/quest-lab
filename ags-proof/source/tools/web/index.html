Proof instructions, save backup and engine details

This is a small original test adventure, not a Quest for Glory remake. Pick the herb in the courtyard, enter the door, talk to Mira and offer the herb. The garden opens after the reward; its entrance is at the courtyard's lower left.

Typed commands use AGS's parser. Discover actions from the room and conversation. The HTML input supports phone keyboards. The browser shell contains no quest rules.

Save confirmation waits for IndexedDB persistence. Browser storage can still be cleared by the browser/user. Use a backup for important progress. Close other proof tabs before playing.

AGS source and license · Engine 3.6.3.17, shared native project for both input styles. Artwork here is procedural test art.
