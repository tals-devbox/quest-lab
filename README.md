# Quest Lab

Static personal review build, with device-local game data and saves. Open https://tals-devbox.github.io/quest-lab/ . Import your private QuestLab-GameData.questlab file once. Original game files, private saves, logs and local revision history are not published.

Source code is in src/. The generated build uses Phaser3 (MIT) and js-dos6.22.60 (GPL-2.0-or-later); the bundled interpreter/audio components follow their SPDX notices. Third-party game data remains separately imported. js-dos source: https://github.com/caiiiycuk/js-dos/tree/6.22.60 .

Incomplete reconstruction; see release.json. Published history is read-only; prompt changes are developed locally and redeployed. Save export/import moves progress between browsers. Clearing browser site data removes local saves and imported game data.
